# IPO 追踪器 | HK IPO Tracker

Raymond 的智能 IPO 追踪应用，结合 AI 分析功能。

## 🎯 功能特色

- **📅 新股日历** — 追踪即将上市的新股
- **🌙 暗盘行情** — 实时暗盘价格涨跌
- **💼 持仓管理** — 管理你的 IPO 中签记录
- **🤖 AI 智能分析** — 基于 MiniMax API 提供新股分析

## 🛠️ 技术架构

| 项目 | 技术 |
|------|------|
| 前端框架 | Bootstrap 5 |
| AI 集成 | MiniMax API |
| 字体 | Noto Sans HK |
| 图标 | Bootstrap Icons |
