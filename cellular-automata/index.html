📚 What is Cellular Automata?

Elementary CA uses a 1D grid where each cell looks at its neighbors (left, self, right) to decide its next state based on a rule number (0-255).

Conway's Game of Life (the classic!) uses 2D - each cell checks its 8 neighbors. Rules: Lonely = born if 3 neighbors, Survive with 2-3 neighbors, Overcrowd/starve = dies.

Try different rules! Rule 30 shows chaos, Rule 110 is Turing complete, Rule 184 models traffic flow.
